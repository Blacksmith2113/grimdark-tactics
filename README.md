# Strategema Bellum

[Stratagema Bellum] is a 2D turn-based tactical strategy game inspired by tabletop miniature wargames. Command a squad-based army across a grid battlefield, where every turn is split into distinct phases: movement, shooting, charge, and melee combat. Combat is resolved through dice-roll mechanics (to-hit, to-wound, and armor saves), so careful positioning, use of cover, and smart unit composition matter just as much as luck. Build your force within a points budget, capture objectives, and outmaneuver your opponent in a grimdark sci-fi setting.

Built with Godot 4 and C#.
